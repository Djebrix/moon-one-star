## The line

> 1 star. The Moon ghosted me for two weeks, then came back full of itself like nothing happened.

95 characters — inside the 120-character limit.

## How it works

`main.py` (Python stdlib only) writes exactly one line, with no trailing
newline, to `/output/entry.txt` (or to the path given as its first argument).
It asserts the line is 1–120 characters and has no leading or trailing
whitespace, so the gate can never see an invalid entry. Two runs produce
byte-identical output.
